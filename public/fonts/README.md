# Self Modern

Not available on Google Fonts — it's a [Velvetyne Type
Foundry](https://velvetyne.fr/fonts/self-modern/) release under the SIL Open
Font License.

Drop these two files here and the site picks them up automatically (see the
`@font-face` rules at the top of `src/styles/global.css`):

- `SelfModern-Regular.woff2`
- `SelfModern-Italic.woff2`

Until they exist, `--serif` falls back to Newsreader.

If you have `.otf`/`.ttf` instead, convert them to `.woff2` first — it is
roughly a third of the file size and every current browser supports it.
